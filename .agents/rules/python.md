# Regra python
Python 3.12+; tipagem explícita e Pyright strict; não usar typing.Any nem casts como fuga. Classes/métodos próprios em português; módulos e pacotes próprios com duas palavras separadas por `_` (exceções de ferramenta); uma classe principal por arquivo. Usar @override nas sobrescritas; @final onde justificável; exceções de domínio encadeadas; pytest. Nunca mascarar erros.
