# escrever-specs
Mapeie cada requisito das linhas finais do arquivo em `docs/requisitos_originais.txt` para `specs/`. Registre cenários, dados de entrada/saída, critérios de aceite e alternativas. Ao terminar, gere documento em `production_artifacts/pm/` e exija aprovação do humano.
