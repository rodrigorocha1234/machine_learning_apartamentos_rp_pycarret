# Critérios de aceite
- [ ] YAML aceita colunas, filtros, features, imputers, modelos e motores por flags independentes; alterações validadas sem mudança de código.
- [ ] XLSX → staging → EDA prova origem do staging.
- [ ] Transformações perigosas (`__import__`, `open`, attribute traversal) são rejeitadas.
- [ ] PyCaret não importa sklearn.model_selection nem busca/tuning scikit-learn por conta própria; usa APIs oficiais para tuning/CV/finalização.
- [ ] Sklearn não invoca funções PyCaret.
- [ ] Folds idênticos e estatísticas de seleção auditáveis.
- [ ] Treino / holdout respeitam separação e logs de parâmetros no MLflow.
- [ ] API MLflow Serving expõe preço do modelo campeão + colunas derivadas de regras de negócio configuradas dinamicamente no YAML com fórmulas Python via AST; sem FastAPI.
- [ ] Dashboards Grafana existem e possuem painéis para EDA, estatística e observabilidade.
- [ ] Pyright strict, pytest, contratos e segurança aprovados.
- [ ] Sem deploy ou promoção sem autorização humana.
