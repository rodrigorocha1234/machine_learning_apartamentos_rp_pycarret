Solução corporativa e modular em Python 3.12+ com tipagem estrita, isolamento físico de frameworks (PyCaret & Scikit-Learn), seleção estatística por Friedman/Nemenyi, ensemble com 7 técnicas de votação e deploy nativo via MLflow Serving com avaliação restrita de AST.

1 Arquitetura de Software e Decisões de Design

O projeto implementa rigorosamente os princípios SOLID e padrões GoF (Strategy, Factory, Adapter, Facade) através de contratos estritos definidos com typing.Protocol. Não foram utilizados frameworks web desacoplados como FastAPI; o modelo final é servido de forma nativa e conteinerizada através da abstração mlflow.pyfunc.PythonModel.

🏛️ Contratos Estritos (Protocols)

Toda a comunicação interna obedece a interfaces semânticas independentes de implementação:

  • ModeloPreditor: Inferência tabular unificada
  • MotorTreino: Validação cruzada e tuning
  • MotorTabela: Vetorização Pandas / Polars
  • FonteDados: Ingestão polimórfica

⚡ Tipagem Pura sem "object"

Em conformidade com as regras de governança, o tipo object e typing.Any foram totalmente extintos. Foram criados Type Aliases semânticos recursivos (PEP 695) como ValorConfiguracao, ValorMetricaParametro e ValorResultadoPipeline.

🛡️ Trilha de Motores Isolados

O framework PyCaret utiliza exclusivamente suas chamadas nativas de alta performance (RegressionExperiment). A trilha Scikit-Learn opera de forma 100% independente com Pipeline, ColumnTransformer e buscas dedicadas.

2 Camada Estatística Independente: Testes de Friedman e Nemenyi

A escolha do modelo campeão não é baseada apenas na média simples de um único fold. Adotamos o protocolo estatístico formal de Janez Demšar (2006), que assegura que o modelo vencedor é significativamente superior aos demais em uma bateria pareada de validação cruzada.

2.1. Teste Não-Paramétrico de Friedman

Compara $k$ algoritmos avaliados sobre $N$ blocos pareados (folds da validação cruzada). Para cada fold $i$, os modelos recebem postos de $1$ (menor erro RMSE) até $k$ (maior erro).

Estatística Qui-Quadrado de Friedman:
χ²_F = [12N / (k * (k + 1))] * [ Σ (R_j)² - (k * (k + 1)²) / 4 ]

Onde $R_j = \frac{1}{N} \sum_{i=1}^N r_i^j$ representa o posto médio do modelo $j$. Se o $p$-valor for inferior ao nível de significância configurado (ex: $\alpha = 0.05$), rejeita-se a hipótese nula de que todos os regressores possuem comportamento idêntico.

2.2. Pós-Teste de Nemenyi e Diferença Crítica (CD)

Após a rejeição de $H_0$ por Friedman, o teste de Nemenyi calcula a Diferença Crítica (CD) para comparações pareadas sem inflacionar o erro Tipo I (falsos positivos):

CD = q_α * sqrt( (k * (k + 1)) / (6 * N) )

Se a diferença entre os postos médios de dois modelos $|R_a - R_b| > CD$, a diferença de performance é estatisticamente significante. O modelo com menor posto médio absoluto é eleito o Modelo Campeão Estatístico.

4 Guia de Expressões Seguras: Pandas & Polars via AST

Para assegurar máxima flexibilidade sem violar a segurança, o sistema oferece suporte a expressões declarativas configuradas no arquivo YAML. O interpretador de AST (Abstract Syntax Tree) restrito compila e executa as expressões diretamente sobre as estruturas colunares dos motores.

Filtros de Registros (Boolean Masking)

Elimina amostras que violam integridade física ou regras de negócio antes do staging:

configuracoes/projeto.yamlFiltros Tabulares
filtros:
  ativo: true
  expressoes:
    # Garante metragens fisicamente válidas
    - nome: metragem_positiva
      ativo: true
      expressao:
        pandas: "df['Metragem'] > 0"
        polars: "pl.col('Metragem') > 0"

    # Preço mínimo de venda realista em Ribeirão Preto
    - nome: preco_minimo_valido
      ativo: true
      expressao:
        pandas: "df['Valor_da_Venda'] >= 50000"
        polars: "pl.col('Valor_da_Venda') >= 50000"

    # Descarte de condomínio inconsistente negativo
    - nome: condominio_consistente
      ativo: true
      expressao:
        pandas: "df['Valor_do_Condominio'] >= 0"
        polars: "pl.col('Valor_do_Condominio') >= 0"

Transformações de Colunas Existentes

Aplica mutações diretamente na coluna de destino especificada:

configuracoes/projeto.yamlTransformações In-Place

  expressoes:

      expressao:

        polars: "pl.col('Metragem').clip(lower_bound=15)"

    - nome: vagas_imputadas
      ativo: true
      destino: Vagas_Garagem
      expressao:
        pandas: "df['Vagas_Garagem'].fillna(1)"
        polars: "pl.col('Vagas_Garagem').fill_null(1)"

5 Catálogo dos 10 Modelos de Machine Learning

O pipeline suporta 10 algoritmos de regressão configuráveis, disponíveis tanto na trilha Scikit-Learn quanto na trilha PyCaret:

1. Regressão Linear Múltipla

Conceito: Modelo linear clássico por Mínimos Quadrados Ordinários (OLS).

  • Vantagens: Rápido, determinístico e 100% interpretável por coeficientes.
  • Atenção: Sensível a multicolinearidade e não captura efeitos não-lineares.
  • Uso em RP: Baseline de comparação para apartamentos padrão.

2. Regressão Lasso (L1)

Conceito: Penalização L1 que zera coeficientes de variáveis irrelevantes.

  • Vantagens: Seleção automática de atributos e redução de ruído.
  • Atenção: Exige padronização das features (StandardScaler).
  • Uso em RP: Descarta variáveis esparsas ou redundantes de bairros.

3. Regressão Ridge (L2)

Conceito: Regularização Tikhonov que encolhe coeficientes evitando overfitting.

  • Vantagens: Excelente estabilidade matemática contra multicolinearidade.
  • Atenção: Não anula coeficientes; mantém todas as variáveis no modelo.
  • Uso em RP: Ideal quando há correlação forte entre Metragem e Cômodos.

4. ElasticNet (L1 + L2)

Conceito: Combinação linear balanceada das penalidades L1 e L2.

  • Vantagens: Mantém grupos de variáveis correlacionadas com seleção esparsa.
  • Atenção: Requer ajuste de dois hiperparâmetros (alpha e l1_ratio).
  • Uso em RP: Equilíbrio ótimo em bases com múltiplos atributos cadastrais.

5. Árvore de Decisão (DecisionTree)

Conceito: Partição binária recursiva baseada no critério de redução de variância.

  • Vantagens: Captura interações não lineares complexas sem escalonamento.
  • Atenção: Alta propensão ao sobreajuste se não podada (max_depth).
  • Uso em RP: Segmentação natural de faixas de preço por zona geográfica.

6. Random Forest Regressor

Conceito: Ensemble Bagging de múltiplas árvores com amostragem aleatória.

  • Vantagens: Altamente robusto a ruídos e outliers; baixa variância.
  • Atenção: Maior consumo de memória e tempo de treinamento.
  • Uso em RP: Um dos modelos mais consistentes para precificação imobiliária.

7. Support Vector Regression (SVR)

Conceito: Encontra um hiperplano ótimo dentro de uma margem de tolerância ε.

  • Vantagens: Eficaz em espaços de alta dimensão usando Kernel RBF.
  • Atenção: Custo computacional quadrático com número de amostras; sensível a escala.
  • Uso em RP: Excelente precisão em nichos de imóveis homogêneos.

8. Rede Neural MLP (Multi-Layer Perceptron)

Conceito: Rede neural densa feedforward com retropropagação de erro (Adam).

  • Vantagens: Aproximador universal de funções e padrões intrincados.
  • Atenção: Exige dados escalonados e ajuste de camadas/neurônios.
  • Uso em RP: Explora correlações não-lineares sutis em grandes volumes.

9. XGBoost (Extreme Gradient Boosting)

Conceito: Boosting com árvores de gradiente de 2ª ordem e regularização formal.

  • Vantagens: Performance competitiva máxima em dados tabulares.
  • Atenção: Requer monitoramento de learning_rate para evitar sobreajuste.
  • Uso em RP: Frequentemente o modelo de menor RMSE em competições imobiliárias.

10. LightGBM (Light Gradient Boosted Machine)

Conceito: Gradient boosting baseado em histogramas com crescimento leaf-wise.

  • Vantagens: Velocidade de treino ultrarrápida e baixo consumo de RAM.
  • Atenção: Em bases pequenas pode sobreajustar rapidamente se leaf-wise for profundo.
  • Uso em RP: Alta performance para re-treinamento contínuo em larga escala.

6 As 7 Técnicas de Votação (Ensemble)

A FabricaVotacao permite combinar as previsões dos $N$ melhores modelos eleitos por Friedman:

Técnica no YAML Mecanismo de Combinação Vantagem Estratégica
media_simples Média aritmética uniforme entre os modelos componentes. Reduz a variância sem custo computacional adicional.
voting_regressor Instância oficial do VotingRegressor do Scikit-Learn. Padrão ouro do ecossistema Scikit-Learn com suporte nativo a pipelines.
media_ponderada_rmse Pesos inversamente proporcionais ao RMSE obtido em CV: $w_i \propto \frac{1}{\text{RMSE}_i}$. Dá maior protagonismo aos modelos que erraram menos na validação.
media_ponderada_postos Pesos decrescentes atribuídos segundo o ranking de Friedman. Ponderação matematicamente robusta que não é distorcida por magnitudes de erro.
mediana Mediana das previsões individuais para cada linha da inferência. Imune a modelos que produzam predições aberrantes (outliers extremos).
media_aparada Trimmed Mean: Descarta a menor e maior previsão por amostra e calcula a média central. Filtra extremidades mantendo o dinamismo da média.
stacking Meta-aprendizado via StackingRegressor com meta-modelo (ex: RidgeCV). Aprende a ponderação ótima de combinação através de validação cruzada out-of-fold.

7 Manual Completo do Arquivo configuracoes/projeto.yaml

O arquivo YAML centraliza todas as decisões variáveis do projeto. A seguir está a descrição de cada chave:

Estrutura das Seções do YAML

  • projeto: Metadados, coluna alvo (Valor_da_Venda) e semente randômica (semente: 42).
  • fonte: Provedor de dados (tipo: xlsx | sql | api), caminho, queries SQL ou endpoints HTTP com suporte a variáveis de ambiente.
  • tabular: Motor de processamento (motor: pandas | polars), modo lazy/eager e limites de memória.
  • filtros, transformacoes, atributos_novos: Expressões em AST para limpeza e feature engineering.
  • framework: Escolha do motor de ML (motor: pycaret | sklearn).
  • modelos: Lista declarativa com os 10 modelos e flag ativo: true/false para seleção pontual.
  • tuning: Ativação, iterações e método de busca:
    • Sklearn: random (RandomizedSearchCV), grid (GridSearchCV), halving_random, halving_grid.
    • PyCaret: random, grid, bayesian, optuna.
  • validacao: Holdout (ex: 0.2), CV externa (repeated k-fold) e CV interna (k-fold).
  • estatistica: Nível de significância (alpha: 0.05) e desempate para o teste de Friedman.
  • votacao: Ativação do ensemble e escolha de uma das 7 técnicas de combinação.
  • regras_negocio: Regras de pós-processamento aplicadas em tempo real pelo ModeloServico.
  • mlflow: Tracking URI, nome do experimento e registro de modelo.
